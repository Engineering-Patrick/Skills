## How to Create Your Own Skills

Replace this content with your actual skill. Skills are markdown files that:
- Have YAML frontmatter with `name` and `description`
- Get triggered via `/skillname` commands
- Can contain instructions for how I should approach tasks

## Example Use Cases

- Custom build/deploy procedures
- Project-specific workflows
- Specialized review checklist
- Domain-specific analysis patterns
